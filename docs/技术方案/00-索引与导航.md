# 索引与导航

2026-09-05 新增 [Astro 功能对齐规范与本轮验收](./Astro适配/02-功能对齐实施方案.md)及 [Astro 包使用说明](../../packages/astro/README.md)。当前代码已接入原生/React 岛屿定位、数据链路、Ask、外部 Agent 和 Astro 可信检查；仍未发布 npm。首轮 [源码设计](./Astro适配/00-方案与验收.md)与[验收记录](./Astro适配/01-实施与验证记录.md)保留为历史，不能替代本轮功能证据。

本文是 SpotPatch v1 核心、v1.1 可选 AI 扩展、v1.2 产品化工作台、Next.js 支持规划与上下文问答目标方案的规范性开发文档。它定义产品边界、支持矩阵、架构、源码组织、模块职责、公共 API、通信协议、安全要求、关键算法、测试方式和验收标准。实现与本文冲突时，应先更新设计决策，再修改代码，避免“代码先跑起来、规则后补”的失控状态。其中 `上下文问答/` 当前仅是已完成的目标设计，不表示代码已实现。

本页只负责导航、追溯和规范治理，不重复定义任何业务常量、协议或数据模型。拆分后的活动规范共同构成完整的 v1/v1.1/v1.2 开发依据；AI 扩展默认关闭，不改变核心多目标 Prompt 工作台的独立可用性。`Next适配/` 同时记录已分发的 0.x 公共预览和仍待完成的正式支持矩阵；包可安装不代表已经正式支持。
