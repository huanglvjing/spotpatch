# 索引与导航

本文是 SpotPatch v1 核心、v1.1 可选 AI 扩展、v1.2 产品化工作台与 Next.js 适配规划的规范性开发文档。它定义产品边界、支持矩阵、架构、源码组织、模块职责、公共 API、通信协议、安全要求、关键算法、测试方式和验收标准。实现与本文冲突时，应先更新设计决策，再修改代码，避免“代码先跑起来、规则后补”的失控状态。

本页只负责导航、追溯和规范治理，不重复定义任何业务常量、协议或数据模型。拆分后的活动规范共同构成完整的 v1/v1.1/v1.2 开发依据；AI 扩展默认关闭，不改变核心多目标 Prompt 工作台的独立可用性。`Next适配/` 是 `implementation-status: planned` 的活动提案，不代表已经交付或发布。
