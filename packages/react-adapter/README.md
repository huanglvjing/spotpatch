# @spotpatch/react-adapter

The isolated React/Fiber compatibility boundary used by SpotPatch to associate
rendered host elements with probable business components and source markers.

Applications should install and configure
[`@spotpatch/vite`](https://www.npmjs.com/package/@spotpatch/vite). This package
is published so the entry package has a complete, versioned dependency graph;
it is not a separate integration surface.
