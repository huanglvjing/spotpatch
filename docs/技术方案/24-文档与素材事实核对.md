## 素材说明

精选使用用户确认的 V2 双语素材，保存于 `docs/assets/readme-v2/{en-US,zh-CN}/`。每种语言包含：3D 产品主视觉、3D 架构、工作台、数据链路、审阅、灵动岛状态、持续 Shell 结构及 GIF。SHA-256 与类型记录在 [manifest](../assets/readme-v2/manifest.json)。

- 3D PNG 使用内置 image_gen 生成/本地化，保留 SpotPatch 原有 Logo；不是运行截图。
- SVG 是规范重绘，源码路径、目标、Diff 和数据均为示例，不表示该视觉已实现为产品样式。
- GIF 是预设的 12 秒概念演示，不连接真实 Agent，不执行修改或检查。README 文案明确区分它与真实事件驱动。
- 架构 PNG 用于职责分层；精确包依赖在双语架构导读的 Mermaid 中，以 package.json 为依据。
- 旧截图不再在根 README 引用；保留原始仓库文件，避免破坏其他历史文档引用。
